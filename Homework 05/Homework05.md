# Numerical Stability of Legendre Polynomials

## 1. Project Objective

This project investigates the numerical stability of computing the ordinary Legendre polynomials $P_\ell(x)$ for fixed order $m=0$ and degrees

$$
\ell = 0,1,\ldots,50,
$$

at the values

$$
x = 0.1,\;0.5,\;0.9,\;0.99.
$$

Three computational approaches are compared:

1. the direct forward recurrence, using `double`-precision arithmetic;
2. a reference sequence computed using high-precision arithmetic;
3. a Miller-type backward recurrence, initialized with arbitrary conditions and subsequently rescaled.

## 2. File Organization

- `legendre_stability.c`: contains all numerical functions and the main program;
- `plot_results.py`: reads the numerical results and generates the plots;
- `Makefile`: automates compilation, execution, and plotting;
- `results.dat`: table generated by the executable;
- `relative_error.png`: plot of the relative errors;
- `absolute_error.png`: plot of the absolute errors.

The last three files are generated by the `make` command and can be removed with `make clean`.

## 3. C Implementation

### 3.1 Forward Recurrence

The `legendre_forward` function initializes

$$
P_0(x)=1,\qquad P_1(x)=x,
$$

and computes the subsequent degrees using Bonnet's recurrence:

$$
P_{\ell+1}(x)=
\frac{(2\ell+1)xP_\ell(x)-\ell P_{\ell-1}(x)}{\ell+1}.
$$

The values are stored in the array `P`. The computation is performed in double precision (`double`).

### 3.2 Reference Values

The `legendre_reference` function uses the same recurrence, but with an MPFR precision of 256 bits. The values are ultimately converted to `double`, since the comparison with the other sequences is performed using this type.

MPFR reduces the reference round-off error to a negligible level compared with that of the standard computation. If the MPFR header is unavailable, the code provides a fallback based on `long double`; the supplied Makefile nevertheless requires the MPFR and GMP libraries during linking.

### 3.3 Backward Recurrence

The forward recurrence is rearranged to obtain $P_{\ell-1}$:

$$
P_{\ell-1}(x)=
\frac{(2\ell+1)xP_\ell(x)- (\ell+1)P_{\ell+1}(x)}{\ell}.
$$

The `legendre_backward_experiment` function starts from

$$
Q_{L+1}=0,\qquad Q_L=1,
$$

with $L=80$ and computes the values down to $Q_0$. These initial conditions are not chosen to represent the Legendre polynomials exactly; they are deliberately arbitrary, as required by the Miller experiment.

To impose the correct normalization at degree zero, the following factor is used:

$$
c=\frac{1}{Q_0},\qquad P_\ell^{(back)}=cQ_\ell.
$$

This ensures that $P_0^{(back)}=1$, but normalization at degree zero alone does not guarantee that the remaining degrees coincide with $P_\ell(x)$.

### 3.4 Errors

For each value of $x$ and each degree, the following quantities are computed:

- absolute error:

$$
E_{abs}=|P_\ell^{(computed)}-P_\ell^{(ref)}|;
$$

- relative error:

$$
E_{rel}=\frac{|P_\ell^{(computed)}-P_\ell^{(ref)}|}{|P_\ell^{(ref)}|}.
$$

When the reference value is very close to zero, the code uses the absolute error as a fallback in order to avoid a numerically problematic division.

## 4. Output Format

The executable prints a header followed by one row for each pair $(x,\ell)$. The `Makefile` redirects this output to the file `results.dat`.

The columns are:

| Column | Meaning |
|---|---|
| `x` | argument value |
| `l` | degree $\ell$ |
| `P_ref` | reference value |
| `P_forward` | value obtained with the forward recurrence |
| `P_backward_exp` | value obtained with the backward recurrence |
| `abs_err_forward` | absolute error of the forward method |
| `rel_err_forward` | relative error of the forward method |
| `abs_err_backward` | absolute error of the backward method |
| `rel_err_backward` | relative error of the backward method |

The program produces $4\times 51=204$ data rows, in addition to the header and the blank lines separating the different values of $x$.

## 5. Plots

The `plot_results.py` script uses NumPy to read `results.dat` and Matplotlib to create two figures:

- `relative_error.png`: shows the relative error on a logarithmic scale as a function of $\ell$;
- `absolute_error.png`: likewise shows the absolute error on a logarithmic scale.

For each value of $x$, two curves are plotted: one for the forward method and one for the backward method.

The logarithmic scale makes it possible to display very small errors and variations across several orders of magnitude simultaneously. The plots use a lower bound of $10^{-20}$ to avoid problems when the computed error is exactly zero.

## 7. Answers of questions in point 4.4

### 7.1 Why Does a Three-Term Recurrence Have Two Independent Solutions?

A three-term recurrence relates three consecutive values, such as $P_{\ell-1}$, $P_\ell$, and $P_{\ell+1}$. Two independent initial conditions are required to determine a solution. Consequently, the solution space is two-dimensional: a general solution can be written as a linear combination of two independent solutions.

For Legendre's equation, in addition to the regular solution $P_\ell(x)$, one can consider a second independent solution, commonly denoted by $Q_\ell(x)$, the Legendre function of the second kind. The sequence generated by the arbitrary initial conditions of the backward method is generally a combination of both:

$$
R_\ell(x)=aP_\ell(x)+bQ_\ell(x).
$$

Normalization using $R_0=1$ changes only the overall coefficients; in general, it does not eliminate the contribution of the second solution.

### 7.2 When Is Miller's Algorithm Effective?

Miller's algorithm is effective when the desired solution is the **minimal** solution in the direction in which the recurrence is propagated. In this case, errors associated with the dominant solution tend to be attenuated during propagation. The resulting sequence can then be rescaled using a known normalization condition.

If the desired solution is not minimal, however, numerical errors or unwanted components introduced by the initial conditions may persist or grow. Backward propagation alone does not automatically make the method stable.

### 7.3 Why Does the Backward Experiment Fail to Select $P_\ell$ for $|x|<1$?

For the values considered, $x$ belongs to the interval $(-1,1)$. In this interval, the two independent solutions are oscillatory and do not exhibit a clear separation into a dominant and a minimal solution that would allow the backward method to select $P_\ell$ automatically.

The conditions $Q_{L+1}=0$ and $Q_L=1$ therefore introduce a combination that is not generally proportional to the sequence $P_\ell$. Imposing $Q_0=1$ subsequently corrects only the overall scale factor, not the shape of the sequence at the subsequent degrees.

This is visible in the data. For example, for $x=0.1$ and $\ell=1$, the reference value is $0.1$, whereas the backward value is approximately $2.58$, with a relative error of about $24.8$. Even for $x=0.99$, where the effect is less pronounced, the backward error at degree 50 is approximately $0.1$, whereas the forward error is of the order of $10^{-15}$.

### 7.4 Why Is the Forward Method Stable in the Tested Cases?

The forward recurrence starts from the exact values $P_0=1$ and $P_1=x$. For the selected degrees and values of $x$, round-off errors are not significantly amplified. Indeed, comparison with the high-precision reference generally shows forward errors close to double-precision accuracy, approximately $10^{-15}$, up to $\ell=50$.

This result is specific to the tested interval and degrees; it does not imply that every forward recurrence for special functions is always stable. Stability depends on the recurrence, the parameter region, and the solution being computed.

### 7.5 Connection with Spherical Harmonics

For $m=0$, the spherical harmonic is

$$
Y_{\ell 0}(\theta,\phi)=
\sqrt{\frac{2\ell+1}{4\pi}}P_\ell(\cos\theta).
$$

The normalization factor depends only on $\ell$ and is known exactly. Therefore, for fixed $\ell$ and $\theta$, an error in the computation of $P_\ell(\cos\theta)$ is transferred directly to $Y_{\ell 0}$, multiplied by the same factor:

$$
\Delta Y_{\ell 0}=
\sqrt{\frac{2\ell+1}{4\pi}}\,\Delta P_\ell.
$$

Similarly, when $P_\ell(\cos\theta)\ne 0$, the relative error in $Y_{\ell 0}$ is equal to the relative error in $P_\ell$, because the normalization factor cancels in the ratio.

## 8. Conclusions

For $x=0.1,0.5,0.9,0.99$ and $\ell\leq 50$, we observe that:

- the double-precision forward recurrence reproduces the high-precision reference very accurately;
- the backward recurrence with arbitrary initial conditions does not generally recover the polynomials $P_\ell(x)$;
- normalization at $\ell=0$ is not sufficient to eliminate the unwanted independent solution;
- Miller's algorithm is useful when the desired solution is minimal in the propagation direction, a condition that is not cleanly satisfied by the experiment on ordinary Legendre polynomials for $|x|<1$.
